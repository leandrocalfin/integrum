¿Dónde se aloja el sitio?

El sitio web se aloja en un servidor. Hay opciones gratuitas y pagas: las gratuitas alcanzan para sitios informativos con poca información, y las pagas suman más espacio, velocidad y recursos cuando el proyecto crece.

Para este tipo de sitio, que almacena poca información, recomiendo empezar con el alojamiento gratuito. Si más adelante agregás funciones más complejas, como una agenda de turnos, se puede probar con el gratuito y, si el sitio crece mucho, pasar a uno pago.

Como referencia, un alojamiento pago cuesta aproximadamente $250.000 por 2 años.

Mantenimiento

Como toda tecnología, los sitios web avanzan y se actualizan con el tiempo: cambian los sistemas, los navegadores y las medidas de seguridad. Por eso se recomienda hacer una revisión de mantenimiento cada seis meses con un programador, para detectar y corregir posibles fallas, actualizar componentes y mantener el sitio funcionando correctamente.

Este trabajo no tiene un costo fijo: se cotiza en el momento, según lo que necesite el sitio en cada revisión.
